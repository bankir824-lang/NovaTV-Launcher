# Nova home Launcher 0.8

Русскоязычный лаунчер для Android TV / Google TV. `applicationId: ru.novatv.launcher`, версия 0.8.0, `versionCode: 9`. Минимальная версия Android — 9 (API 28).

## Скачать APK

Готовые версии публикуются на странице [Releases](https://github.com/bankir824-lang/Nova-home-Launcher/releases) только из основной ветки `main`. Артефакты сборок pull request предназначены для проверки и не считаются опубликованными версиями.

Для установки откройте последний релиз, скачайте APK из раздела Assets и установите его на Android TV / Google TV.

## Интерфейс

Главный экран — ряды ТВ-приложений, мобильных приложений, избранного и пользовательских категорий. Для ТВ используются баннеры из установленных пакетов; при их отсутствии — настоящая иконка приложения. Пустое избранное из скрытых приложений не создаёт пустой ряд. Обычный OK запускает приложение, удержание OK открывает меню без пункта «Открыть». Поддерживаются DPAD_CENTER, ENTER и NUMPAD_ENTER. Повторы клавиши не создают дополнительных запусков или меню. Потеря фокуса карточки/окна, удаление карточки и отменённое отпускание отменяют ожидающее нажатие.

Короткое OK на кнопке «Настройки» открывает панель Nova, а удержание OK — системные настройки Android. Кнопка MENU пульта открывает и скрывает панель Nova. «Назад» возвращает на прежний пункт предыдущей страницы с сохранением прокрутки. Панель выезжает справа, занимает треть ширины экрана и располагается между верхней строкой и нижним отступом. Стрелки пульта меняют значения ползунков.

**Настройки Nova home Launcher:**

- Главный экран → Ряды: независимое оформление каждого ряда и группы рекомендаций, до восьми рядов в сетке, десять размеров карточек, подписи внутри или под плиткой, увеличение при фокусе. Баннеры приложений используются автоматически, если доступны.
- Главный экран → Оформление рядов: отступы, заголовки, значки категорий и фокус. Верхний отступ считается от нижнего края видимой панели.
- Обои: изображения и GIF через системный проводник, локальные видеообои без звука, затемнение, вписывание изображения и три темы фона. Видео и GIF приостанавливаются, когда Nova home Launcher не виден. Доступ к файлу сохраняется через SAF. Возможность выбора файла зависит от наличия проводника, воспроизведение видео — от кодеков ТВ.
- Верхняя панель: общая видимость, отдельная видимость двух блоков, перестановка кнопок внутри блоков, Bluetooth и единый размер текста. Цвета выбираются в боковой палитре с яркостью и непрозрачностью.
- Оформление интерфейса: шрифт и цвет акцента.

**Главный экран → Управление категориями:** создание, выбор приложений, видимость, переименование, порядок и удаление. «Управление избранным» находится внизу настроек ряда «Избранное». Перестановка с пульта: удержание OK, стрелки, OK — сохранить, Назад — отменить.

**Все приложения:** боковой список с настоящими баннерами/иконками и меню по удержанию OK. Скрытые приложения доступны в настройках главного экрана; восстановление через меню «Показать приложение» сохраняет избранное.

## Каналы и системные функции

В «Главный экран → Ряды → Разрешение и обновление каналов» нажмите «Разрешить чтение каналов», чтобы запросить системный доступ к рекомендациям приложений. «Смотреть далее» читается отдельно. В диагностике видны состояние доступа, найденные каналы и число доступных карточек. Nova home Launcher показывает опубликованные приложениями каналы, доступные через TV Provider этой прошивки. В портретном режиме 2:3 постер вписывается целиком. При фокусе показываются год, рейтинг, сезон, жанры и до трёх строк описания, если эти данные переданы приложением. Постеры загружаются по HTTPS или доступным content URI и кешируются в памяти.

Источники сигнала берутся из `TvInputManager`; выбранный вход открывается штатным TV Intent. Доступность входов, заставки, настроек экрана, Bluetooth, голосового поиска и других экранов зависит от прошивки. Недоступный Intent показывает сообщение. Выключение телевизора, изменение системного лаунчера, перехват HOME и сетевой сервер дистанционного управления не добавлены.

Уведомления и «Сейчас играет» доступны после добровольного предоставления доступа Notification Listener в настройках Android. Nova home Launcher не включает разрешение сам. Тексты уведомлений хранятся только в памяти, очищаются при отключении сервиса. Активные медиасессии открываются через предоставленные приложениями PendingIntent.

«Электропитание» позволяет оставить экран включённым только пока виден Nova home Launcher и открыть штатные настройки экрана/заставки. «Основные → Автозапуск» запускает выбранное приложение один раз при новом старте Activity Nova home Launcher, а не при возврате и не при загрузке Android.

## Родительский контроль и профили

PIN на 4–8 цифр защищает настройки и выбранные приложения **внутри Nova home Launcher**. Хранится соль и PBKDF2-HMAC-SHA256, исходный PIN не сохраняется. После трёх неверных попыток — пауза 30 секунд в текущем процессе. PIN не блокирует Google TV, системные настройки, запуск из других приложений и сброс данных Nova home Launcher; это локальное ограничение интерфейса, не системная защита. Если PIN забыт, потребуется очистка данных Nova home Launcher с потерей его настроек.

Профили экрана сохраняют локальные параметры оформления и URI обоев. PIN и список защищённых приложений в профиль не включаются. Профили можно применить и удалить. Сброс оформления сохраняет избранное, категории и установленные приложения.

## Погода

Выберите город в «Верхняя панель → Что показывать → Погода». Поиск города использует службу Android. На устройствах без этой службы координаты можно ввести вручную. Nova home Launcher проверяет прогноз [MET Norway Locationforecast](https://api.met.no/weatherapi/locationforecast/2.0/documentation) каждый час, пока видна верхняя панель, и учитывает срок кеша сервера. Данные [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) округляются до целого градуса. Звёздочка отмечает последнее известное значение при ошибке обновления.

## Сборка и проверки

JDK 17, Android SDK 35, Gradle 8.9:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions выполняет тесты, Lint и сборку для PR, push в main и ручного запуска. APK: `app/build/outputs/apk/debug/app-debug.apk`, артефакт `Nova-home-Launcher-debug`. Отчёты, результаты тестов и изображения Android View: артефакт `Nova-home-Launcher-checks`.

Автотесты проверяют автомат OK, сохранения порядка и скрытых приложений, сетевых ошибок и запросов погоды, геометрии карточек и PIN. Robolectric с native graphics проверяет настоящую Activity при 1920×1080: фильтрацию избранного, открытие/возврат панели, изменение ползунка стрелкой и сохранение фокуса. Изображения в `app/build/reports/ui/` получены из Android View с контролируемыми тестовыми приложениями; это не фотографии телевизора и не доказательство работы кодеков, TV Provider или сетевых сервисов на физическом ТВ.

Для установки поверх предыдущей версии нужны одинаковые applicationId **и сертификат подписи**. Debug-ключи локальной среды и GitHub Actions могут различаться. Используйте ключ прежней установки, если нужно сохранить данные.

## Проверка на Android TV / Google TV

Короткое и длительное OK/ENTER без двойного запуска; вложенные меню и Назад; длительный скролл ползунков; сохранение настроек и фокуса после перезапуска; отдельный порядок категорий; скрыть последнее избранное и восстановить; баннеры приложений; GIF/видеообои и уход/возврат; доступ/отказ TV Provider; включение и отзыв доступа к уведомлениям; PIN и пауза после ошибок; профили и отмена выбора файла; погода из сети телевизора и её диагностика.

Не реализованы все возможности Projectivy один в один: пакеты значков, Lottie/RTSP-фоны, перехват HOME, системное выключение и собственный сетевой пульт не добавлены. Для них нет неработающих переключателей. Новая структура меню и оформление реализованы собственными Android View.
